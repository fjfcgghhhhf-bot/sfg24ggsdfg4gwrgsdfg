# UPGRADE — бесплатная игра со скинами CS2

Тёмный интерфейс по референсу: два выбранных предмета, круг апгрейда с нижним жёлто-оранжевым сектором победы, магазин и каталог. Авторизация и Steam не требуются. При первом входе игрок вводит ник и получает **500 виртуальных ₽**. Реальных платежей и вывода предметов нет.

## Правила

- Купить скин можно в левом блоке, вкладка «Магазин». Выбранный купленный скин становится ставкой.
- Справа выбирается более дорогой предмет. Шанс = цена ставки / цена цели × 100%, без скрытой комиссии.
- Сервер выбирает равномерный случайный угол криптографическим генератором. Цветной сектор расположен по центру нижней части круга. Его угловая ширина равна 360° × вероятности. Попадание в него означает победу; остальная часть — поражение.
- При любом результате исходный скин списывается. При победе целевой скин появляется в инвентаре.
- В верхнем инвентаре скины продаются за полную игровую стоимость. Средства возвращаются на баланс.
- Каталог содержит 49 999 ценовых предложений с шагом 10 ₽, от 10 до 499 990 ₽, и финальный предмет «Код» за 500 000 ₽. Используются 62 реальных изображения скинов; цены игровых предложений вымышлены. Поиск, диапазон цен, сортировка, страницы, множители и подбор по желаемому шансу помогают найти цель.
- Десятизначный код доступен только после удачного апгрейда на этот предмет. Купить его напрямую нельзя. Приз нельзя продать.
- «Повторить сессию» после подтверждения удаляет сохранение этого браузера и позволяет ввести новый ник и получить 500 ₽ снова.

## Запуск

Нужен Node.js 24+. Зависимостей npm нет.

```sh
npm start
# http://localhost:3000
npm test
npm run build
```

При локальном запуске автоматически создаётся `.local-secrets.json`. Этот файл исключён из Git и не раздаётся сервером. Он содержит случайный код и ключ сохранений. Не удаляйте его, если хотите сохранить доступ к локальным сессиям.

## Render

В репозитории есть `render.yaml` для бесплатного Node Web Service. Настройки:

- Build: `npm run build && npm test`
- Start: `npm start`
- Health check: `/health`
- Node: 24+
- `NODE_ENV=production`
- `SESSION_SECRET`: постоянная случайная строка длиной не менее 32 символов
- `GOAL_CODE`: десятизначное число, заданное владельцем в секретной переменной окружения

Публичный репозиторий, браузерные JS-файлы и каталог не содержат реальный код. Не добавляйте его в исходники или публичный Blueprint. При смене `SESSION_SECRET` прежние сохранения перестают открываться. При обычных перезапусках с тем же ключом прогресс сохраняется.

## Сохранения и границы защиты

В `localStorage` браузера хранится зашифрованный AES-256-GCM снимок. Ник, баланс и инвентарь восстанавливаются после обновления страницы, закрытия вкладки и перезапуска сервера с тем же ключом. Результат апгрейда сохраняется до начала анимации. Сохранение привязано к браузеру и адресу сайта; очистка данных сайта удалит его.

Все цены, покупки, продажи и результаты проверяются сервером. В работающем процессе каноническая ревизия защищает от параллельной траты одного предмета, старых запросов и повторного восстановления сброшенной сессии. При потере ответа повторное восстановление возвращает уже совершённый результат.

Это бесплатный симулятор без денежного приза и постоянной базы данных. После перезапуска процесса вручную сохранённый ранее корректный зашифрованный токен может быть повторно предъявлен. Для соревновательной игры или экономически значимого приза необходима постоянная серверная база ревизий и отозванных сессий. Код не следует использовать как финансовый или иной секрет с реальной ценностью.

## Проверки

`node:test` проверяет баланс, диапазоны каталога, покупку/продажу, выигрыши и проигрыши, соответствие угла вероятности, защиту от повторных трат, восстановление после перезапуска, подмену сохранения, недоступность кода до выигрыша, сброс, конфигурацию и HTTP-маршруты. Для детерминированных проверок движку передаётся генератор случайных чисел только через импорт в тесте. Публичного тестового API нет.
